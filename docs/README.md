# Fast-Flow Docs (Docusaurus)

Documentation is built with [Docusaurus](https://docusaurus.io/).

## Prerequisites

- **Node.js** ≥ 20
- **npm** (in project root: `npm install` for workspaces)

## Installation

In the project root:

```bash
npm install
```

Or only in the `docs/` folder:

```bash
cd docs
npm install
```

## Local development

```bash
# From project root
npm run docs:dev
```

or

```bash
cd docs
npm run start
```

Docs run at [http://localhost:3000](http://localhost:3000). Markdown changes reload automatically.

## Build

```bash
# From project root
npm run docs:build
```

or

```bash
cd docs
npm run build
```

Static files are in `docs/build/`. Local preview server: `npm run serve` (in `docs/`).

## Deployment (e.g. GitHub Pages)

```bash
cd docs
npm run deploy
```

For GitHub Pages with SSH: `USE_SSH=true npm run deploy`.  
Without SSH: `GIT_USER=<your-github-user> npm run deploy`.

## Mermaid diagrams

In Markdown, [Mermaid](https://mermaid.js.org/) diagrams are rendered via ` ```mermaid ` code blocks (e.g. in `docs/architektur.md`).

## Admonitions (callout boxes)

`docusaurus.config.ts` sets `future: { v4: true }`, which implies
`mdx1CompatDisabledByDefault: true` and therefore **disables the legacy,
space-separated admonition title syntax**. Titles must be in square brackets:

```markdown
:::caution[Important notice]
Text of the callout.
:::
```

Written as `:::caution Important notice`, the block is **not** rendered as a callout —
the `:::` line ends up as literal text on the page, in dev server and production build
alike. Admonitions without a title (`:::note` on its own line) are unaffected.

Do not remove `future: { v4: true }` to get the old syntax back: the flag is set
deliberately, and dropping it has already broken the build before.

## Structure

- `docs/` – Markdown sources
- `src/` – React components, CSS
- `static/img/` – images, favicon, logo
- `sidebars.ts` – sidebar order (autogenerated from `docs/`)
